使用说明

配合 ros2 launch game_controller launch.py（仿真：本机域 100； 实机：各机器人本机域 10，--target 指向机器人 IP）使用； UDP 面板负责产生 HL v12 数据包，本页无任何 ROS 依赖。

实机在线状态：面板内嵌监听 UDP 3939 的 brain 保活心跳（RGrt 8B，1 Hz）， 3s 无心跳判离线；各实机 brain 的 game_control_ip 需指向本机（裁判机）， 深层机体状态请 SSH 登录机器人本体观测； 若改用独立监视 referee_ui/scripts/start_robot_watch.sh，本面板须加 --no-robot-watch 释放端口。

逐球员罚下：勾选 = PENALTY_MANUAL（40s），未用槽位自动填 SUBSTITUTE，列表全量替换下发。

自动时间线：INITIAL(5s) → READY(10s) → SET(5s) → PLAYING(60s) → FINISHED(3s) 循环。

⚠ 不能双源：若对侧仿真也发送 GC 数据，必须只保留一方发送（本面板可一键停发）。
